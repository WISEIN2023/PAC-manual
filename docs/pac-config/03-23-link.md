# 3. System Config (ZTPACSYS)

## 3.23 Link

### 3.23.1 PORTAL_SEARCH — Active portal link search

**테이블-필드:** ZTPACSYS - PORTAL_SEARCH

**운영 설정(LG전자 설정) :** 미사용

#### 설정 설명

PAC Home의 Link 검색기능 활성화

#### 참조 프로그램 / 오브젝트 (Where-used)

■ ZCL_ZGWPAC_MONITOR_DPC_EXT=>PORTAL_LINK_HDRS_GET_ENTITY(CM00H)

#### 프로세스 관점 분석 (사용 로직)

PAC Home Link 화면의 검색 기능 활성화.

① OData PORTAL_LINK_HDRS Entity로 Fiori Link 화면에 검색창 표시 여부 전달.

#### 영향도 분석 (변경 시 영향)

표시 전용 — 포털 Link 화면의 검색 UI 노출만 변경.

### 3.23.2 PORTAL_LTEXT — Portal Link Header Text

**테이블-필드:** ZTPACSYS - PORTAL_LTEXT

**운영 설정(LG전자 설정) :** Direct Link

#### 설정 설명

PAC Home의 Link 화면의 Text명을 정의

#### 참조 프로그램 / 오브젝트 (Where-used)

■ ZCL_ZGWPAC_MONITOR_DPC_EXT=>PORTAL_LINK_HDRS_GET_ENTITY(CM00H)

#### 프로세스 관점 분석 (사용 로직)

PAC Home Link 화면의 헤더 텍스트.

① Link 영역 타이틀 문자열로 Fiori에 전달.

#### 영향도 분석 (변경 시 영향)

표시 전용 — 포털 화면 타이틀만 변경.
