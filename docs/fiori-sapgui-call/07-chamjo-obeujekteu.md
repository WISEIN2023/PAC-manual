# 7. 참조 오브젝트

본 문서에 등장하는 주요 오브젝트와 시스템 등록 설명을 정리합니다. 설명은 시스템 등록값(영문) 기준입니다.

| 오브젝트 | 유형 | 설명(시스템 등록값) |
|---|---|---|
| ZLPAC_FTCODE | Program / TCode | Call SAP Transaction from Fiori |
| ZLPAC_FTCODE_SIMUL | Program | Call SAP Transaction for Simulation |
| ZLPAC_FTCODE_SNID | Program | Call SAP Transaction for Scenario |
| ZTPAC_PROC | Table | Activity Definition Master |
| ZTPAC_CIS_CID | Table | Closing Inspection Category Master |
| ZCL_PAC_NETGRAPH | Class | Process Automatic Channel - Network |
| ZFPAC_LEGACY_LINK | Function (ZPAC270) | Link Legacy URL |
| ZLPAC7170 | Program / TCode | Change Closing Schedule |
| ZLPAC0600 | Program / TCode | Display To Do |
| ZLPAC5100 | Program / TCode | Financial Risk Validation Monitoring |
| ZLPAC5200 | Program / TCode | Closing Inspection Monitoring |
| ZLPAC5300 | Program / TCode | Closing Inspection by Simulation Run Monitoring |
