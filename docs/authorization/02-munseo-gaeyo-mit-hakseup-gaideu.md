# 1. 문서 개요 및 학습 가이드

## 1.1 권한 운영자가 하는 일 (업무 범위)

엑셀 기초자료 기준, 권한 운영자의 업무는 크게 네 가지입니다.

- **권한 부여:** 사용자에게 PAC Role, Participant, Special Role을 등록
- **신규 권한 생성:** PFCG에서 신규 Role(Master/Variant) 생성, 신규 법인 추가 대응
- **권한 오류 대응:** 사용자가 화면·Activity를 수행하지 못할 때 원인 파악 및 조치
- **운영 권한신청 환경 세팅:** GSOD(운영서버 권한신청 환경) 관리 — LG전자 특화
솔루션 구축의 경우 해당 고객사의 권한 운영 체계에 맞게 PAC Role을 설계하는 절차가 필요하며, 기존 Role 사례를 알고 있어야 합니다.

## 1.2 학습 순서 추천

1. 2장(큰 그림) → 권한의 3대 개념을 먼저 머릿속에 그린다.
2. 3장(SAP 기본기) → PFCG, Role, 테이블/Tcode 등 SAP 공통 지식을 익힌다.
3. 4장(권한 체크 구조) → PAC이 권한을 어떻게 검사하는지 이해한다.
4. 5장(실무 절차) → 프로그램별 등록·변경 방법을 손으로 따라 한다.
5. 6~8장 → Fiori 화면, 실행 유저, OData 등 보조 개념을 익힌다.
6. 9장(LG전자 특화) → 실제 운영 환경의 고객사 특화 내용을 익힌다.
7. 10장(트러블슈팅) → 실제 문의가 들어왔을 때 대응법을 익힌다.
8. 11장(셀프 확인)으로 스스로 점검한다.
