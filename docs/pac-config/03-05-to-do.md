# 3. System Config (ZTPACSYS)

## 3.5 To Do

### 3.5.1 TODOIF — Active To Do Interface

**테이블-필드:** ZTPACSYS - TODOIF

**운영 설정(LG전자 설정) :** 활성화

#### 설정 설명

□ X 활성화시 : To Do를 별도 I/F를 통해 발송한다

#### 참조 프로그램 / 오브젝트 (Where-used)

■ ZFPAC_OPEN_TODO(LZPAC260U01), ZFPAC_CLOSE_TODO(LZPAC260U02)

#### 프로세스 관점 분석 (사용 로직)

To Do 외부 인터페이스 발송 여부.

① ZFPAC_OPEN_TODO/CLOSE_TODO: 'X'이면 GET_TODO_EXIT_FUNCNAME으로 등록된 EXIT 펑션을 통해 외부 시스템(포털 To Do 등)으로 유형별(M:Manual Ready/E:Error/R:Rework/CN·CC·CR·CS:결산점검) 발송, 공백이면 내부 테이블(ZTPAC_TODO_*)에만 기록.

#### 영향도 분석 (변경 시 영향)

해제 시 외부 포털로의 To Do 연동이 중단되고 내부 기록만 남음 — 포털에서 To Do를 확인하는 운영이라면 업무 통지가 끊김.

활성 시 EXIT 펑션(외부 I/F) 장애가 To Do 발송 오류로 직결되므로 I/F 모니터링 필요.
