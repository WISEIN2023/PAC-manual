# 9. 운영 주의사항 (확인 필요 항목)

아래 항목은 소스만으로 단정할 수 없거나, 동작이 설정/외부 시스템에 의존하는 부분입니다. 운영 적용 전 개발팀 또는 운영 환경 설정에서 확정하세요.

1. 완료(XMAIL_COM) 메일의 일부 처리 로직이 반쪽만 반영된 정황. 설정 저장/조회를 SE16N으로 검증 권장.
2. CIS/메신저의 실제 발송 트리거는 ZTPACEXIT(동적 EXIT 함수)에 의존. 등록된 함수명/매핑은 운영 SE16에서 확인 필요.
3. HTML loop 마커 문자열(타입그룹 ZPAC0)은 외부 조회 제한. 기존 양식 본문에서 복사해 사용 권장.
4. 메신저 발송 기능은 현재 미구현 상태(플래그 XMSGR_*만 선택 가능). 고객사에서 요청 시 인터페이스 관련 CSP 로직 개발·추가 필요.
5. 알람 배치 취소(EXEC_MODE='C') 호출 경로는 미확인. 일정 취소/삭제 시 잡 정리 여부를 SM37로 확인 권장.
