# 1. 문서 개요

## 1.1 자주 묻는 질문(FAQ) — 빠른 찾기

자주 받는 질문과 '어디를 보면 되는지'입니다. 빠르게 찾을 때 먼저 보세요.

| 이런 질문일 때 | 짧은 답 / 볼 곳 |
|---|---|
| 메일이 안 왔다는데? | PAC 로그(ZTPAC_LOG_MAIL)에 발송기록 있는지 → 있으면 SOST에서 실제 전송 상태 확인. (7.1 케이스 A, 5.6) |
| 특정 사람만 메일을 못 받아요 | ZTPAC_PROC_AUTH의 수신 플래그(XMAIL_*)·이메일(SMTP_ADDR) 확인. (7.1 케이스 B) |
| 수신자를 추가하려면? | ZLPAC1000에서 원하는 메일 수신항목에 대한 사용자 등록 + 메일 종류 체크박스. (5.2) |
| 고객사별 메일 수신옵션을 통제하려면? | ZLPACSYS |
| 마감 알람은 어떻게 설정? | ZLPAC7200에서 알람시간·수신자 저장 → 배치 자동 예약. (5.4) |
| 메일 본문(양식)을 바꾸려면? | ZLPAC_HTML에서 HTML 양식 수정. 새 데이터는 ABAP 수정 필요. (5.5, 6장) |
| 메일이 실제로 나갔는지 확인? | SOST(SAPconnect 발송 큐). PAC 로그 성공 ≠ 실제 전송. (5.6, 7.1 케이스 A) |
| 본문에 $필드명$이 그대로 나와요 | 양식 마커가 발송 데이터 필드명과 불일치. (7.1 케이스 E, 6장) |
| 문제 원인을 코드로 봐야 할 때(디버깅) | 증상별 중단점 위치 표. (7.2) |
